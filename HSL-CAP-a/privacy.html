01

Overview

HSL CAP is a small collection of local tools. Its reference tool presents the 128 standard ASCII code points together with their decimal, hexadecimal, octal, binary and Unicode representations, and its settings area carries the legal and support information for the product.

This statement covers the mobile application distributed under the name HSL CAP. It is written to be read once, on a phone, without a lawyer.

02

What we collect

Nothing that identifies you reaches us. There is no registration service, no analytics SDK, no crash-reporting pipeline, no advertising identifier and no behavioural profile behind this app.

ChannelWhat happens
Sign-in screen Local only Any account and password is accepted. The values never leave the device.
Usage data Not collected No screens, taps, sessions or timings are recorded or transmitted.
Contacts, photos, location Not accessed These are never read. Images reach the app only if you hand one over yourself.
Device identifiers Not collected No advertising ID, IMEI, MAC address or fingerprint is read.
03

Data stored on your device

Four kinds of information are written to private app storage on your phone. Private storage is not readable by other apps on a non-rooted device, and it is removed entirely when you uninstall HSL CAP or clear its data from Android system settings.

ItemWhereWhy
Signed-in flag App preferences So the app does not ask you to sign in again on the next launch.
Account label App preferences Displayed in the corner of the home screen. It is a label, not a credential.
Saved entries App preferences The ASCII code points you marked with the star control.
Recently viewed App preferences The last twelve code points you opened, shown as shortcuts on the home screen.

To erase all of it at once, open Android Settings → Apps → HSL CAP → Storage and choose Clear storage.

04

The page that opens first

Each time the app starts, a web page is displayed before the tools become reachable. That page is this page, and it is loaded over the network. Because it is a normal web request, the server that hosts it can see standard web signals such as your IP address, the user agent of the browser engine inside the app, and the time of the request. We do not store or profile those signals, but the hosting provider's own logs are outside our control.

The page is allowed to keep cookies and local storage on your device so it does not have to be fetched in full every time. You can clear this data at any moment from Settings → Apps → HSL CAP → Storage → Clear storage.

The page can also ask the app to close itself once you accept it. If your device is offline when the app starts, the page may not load; the tools remain fully usable because none of them need a connection.

05

Permissions

The app requests exactly two permissions, and nothing else.

android.permission.INTERNET android.permission.ACCESS_NETWORK_STATE

INTERNET is used to load this page. ACCESS_NETWORK_STATE is used to detect whether a connection exists so the app can fail gracefully instead of hanging.

The camera is deliberately not requested as a permission. If you choose to attach a photo inside the opening page, the task is handed to the system camera application or the system photo picker, and only the single image you select is shared back to the page. The app itself never opens the camera.

06

Cookies and local storage

The in-app browser that renders this page accepts both first-party and third-party cookies, and has local storage enabled, so pages can remember state between visits. Cookies set here are stored in the app's private WebView data directory and are removed when you clear the app's storage.

We do not set advertising, tracking or cross-site profiling cookies. Any cookie in this container was set by the page you are reading or by a resource it loads.

07

Third-party links and support channels

Some links are opened in your system browser rather than inside the app, including every support and messaging destination. Once you leave, the privacy statement of that destination governs what happens next. HSL CAP passes no local data along with those links.

Destinations that always open in your system browser include:

line.mewa.meqr.kakao.com tawk.toworks.doopen.kakao.com signal.met.me

Links that would open a new browser window are also handed to the system browser instead of being hosted in a second in-app view.

08

Your choices

  • Clear everything. Android Settings → Apps → HSL CAP → Storage → Clear storage.
  • Sign out. Settings → Sign Out returns the app to the sign-in screen and forgets the signed-in flag.
  • Remove saved entries. Open any code point in the ASCII table and tap the star again.
  • Stay offline. Every tool in the app works without a connection.
09

Children

HSL CAP is a general-purpose reference tool and is not directed at children. It contains no advertising, no behavioural profiling and no social features. It does not knowingly collect personal information from anyone, of any age.
